# Colaboración

Este repositorio reúne el trabajo de cinco integrantes. El reparto del documento de referencia es una propuesta que el equipo debe confirmar.

1. Actualizar `main` antes de iniciar una tarea.
2. Crear una rama corta por tarea, por ejemplo `feat/pantalla-inicio` o `docs/flujo-recarga`. Los cambios preparados con Codex usan el prefijo `codex/`.
3. Mantener cada cambio centrado en una tarea y usar datos ficticios.
4. Abrir un pull request explicando qué cambia y cómo se verificó. Adjuntar capturas cuando se modifique una pantalla.
5. Solicitar revisión a otro integrante antes de integrar.

Durante el prototipo, verificar navegación, consistencia visual y estados de éxito y error. Cuando se implemente el PMV, agregar las pruebas pertinentes del plan, especialmente para cobros, permisos y NFC.

No incluir secretos ni credenciales en commits. Las variables necesarias se documentarán con archivos `.env.example` sin valores privados.
